## 🎓 Academic Context & Overview
This repository contains a comprehensive collection of computational algorithms developed for the **Numerical Methods** course at **Universidade Federal Rural do Rio de Janeiro (UFRRJ)**.

The primary objective of this project is to bridge the gap between theoretical calculus/linear algebra and practical software engineering. By implementing these algorithms from scratch across multiple paradigms (using both C and Python), this suite demonstrates how to approximate complex mathematical problems—such as root-finding, continuous data integration, and complex dynamical systems—with high precision and computational efficiency.

*   **Mathematical Modeling:** Translating continuous analytical equations into discrete algorithmic steps.

## 🚀 Implemented Methods & Pipeline

The repository is structured into distinct modules, each tackling a specific domain of numerical analysis:

### 1. Root-Finding Algorithms (Zero of Functions)
*   **Bisection Method:** A robust, bracketing method that guarantees convergence by repeatedly halving subintervals enclosing the root.
*   **Secant Method:** An open method that uses secant lines to better approximate the root, offering faster convergence than Bisection without requiring the calculation of derivatives.

### 2. Curve Fitting & Regression
*   **Method of Least Squares (MMQ):** Implemented to find the best-fitting curve for a given set of data points by minimizing the sum of the squares of the offsets.
*   **R-Squared ($R^2$) Evaluation:** Algorithm to calculate the Coefficient of Determination, providing a statistical measure of how close the data are to the fitted regression line.

### 3. Numerical Integration
*   **Trapezoidal Rule:** 
    *   **Composite Trapezoidal:** Approximates the definite integral by breaking down the area under a continuous function into multiple trapezoids.
    *   **Tabular Trapezoidal:** Adapted to work directly with discrete data points provided in data tables.
*   **Simpson's Rules:** 
    *   **Simpson's 1/3 Rule:** Uses quadratic polynomials for highly accurate approximations of integrals.
    *   **Simpson's 3/8 Rule:** Employs cubic interpolation to handle intervals with an odd number of sub-segments.

### 4. Ordinary Differential Equations (ODEs) & Dynamical Systems
*   **Euler Method:** A foundational first-order numerical procedure for solving ODEs with a given initial value.
*   **Runge-Kutta Methods:** Advanced, high-precision iterative methods for approximating solutions to ODEs.
*   **Predator-Prey Model (Lotka-Volterra):** Applied the ODE solvers to simulate biological dynamics. Utilizing `matplotlib`, the system generates phase portraits and population-over-time graphs to visualize the cyclical relationship between predator and prey populations.

## 📊 Diagnostics & Visualization
To ensure the mathematical validity of the algorithms, visualization scripts were built using **Matplotlib** and **NumPy**. These scripts:
*   Plot the original functions against the curves generated by the Least Squares Method.
*   Graph the iterative convergence steps of the root-finding methods.
*   Render the continuous population dynamics of the Predator-Prey model, clearly showing the stability and oscillations calculated by the Runge-Kutta solver.
